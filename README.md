Basic Java Calculator

A simple console-based calculator built using Java. This project allows users to perform basic arithmetic operations through a menu-driven interface.

Features
Addition
Subtraction
Multiplication
Division
User-friendly console input/output
Handles division by zero errors
Technologies Used
Java
Scanner Class for user input
Switch Case for operation selection
Learning Outcomes
Understanding Java console input/output
Using conditional statements and switch-case
Implementing basic arithmetic operations
Handling runtime errors such as division by zero



This project was created as part of my Java programming learning journey and internship tasks.
